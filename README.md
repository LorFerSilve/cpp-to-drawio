# C++ to Draw.io

A standalone CLI for generating editable Draw.io UML class diagrams from C++
projects and generating C++ skeletons from UML class diagrams.

## Status

In development. The planned workflow uses Clang to analyze C++ projects,
generates editable class diagrams with namespace overviews, and converts diagrams
back into C++ skeletons with Doxygen comments.

## Reference

The CLI conventions, diagram layout, and end-to-end tests follow
[Java to Draw.io v0.4.0](https://github.com/LorFerSilve/java-to-drawio/tree/v0.4.0).
